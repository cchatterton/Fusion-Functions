# Fusion Functions

This repository starts with the supplied `Magic_Card` WordPress PHP source. `Magic_Card.php` is preserved exactly as provided, version 1.8. It is a source snapshot, not yet a packaged WordPress plugin.

The first area under review is rendered-card caching. See [CACHE_REVIEW.md](CACHE_REVIEW.md) for the current behaviour and proposed repair.

Development should follow the applicable standards in [codex-standards](https://github.com/cchatterton/codex-standards). No runtime changes have been made to the supplied source yet.
